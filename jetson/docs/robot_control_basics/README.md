# 로봇제어 기본기 — 정리

> 2026-09-17 세션 정리. "ROBOTIS가 준 걸 쓰다 보면 뭐가 뭔지 모른 채 지저분한 코드를 들고 가게 된다"에서 출발해,
> **로봇 제어가 원래 어떻게 짜이는지**(아키텍처 + 공정)를 조사하고, **무엇부터 해야 하는지**를 정한 기록.

## 한 줄 요약

로봇 제어는 **중첩된 피드백 루프의 사슬**이다 (정책 5–15 Hz → 궤적 제어 100 Hz → 서보 PID ~1 kHz → PWM 수십 kHz).
이 분야의 실체는 **경계 규율** — 층과 층 사이로 *무엇이, 어떤 단위로, 얼마나 자주* 넘어가고, *위층이 멈추거나 거짓말할 때 아래층이 무엇을 하는가*.
검증은 **아래에서 위로, 싼 것에서 비싼 것으로**.
