- 젯슨 오린 나노 네트워크 설정 
    
    ssafy 에서 오린 전용 wifi ip를 할당해주지 않음 이를 위해 기존에 적용된 lan 케이블 전용 ip를 사용 하고자함

    하지만 디스플레이를 다른 사람이 사용 중이기에 ctoc 케이블을 연결해 노트북과 시리얼 통신을 통해 다음 명령어 등을 사용해 유선 연결 설정을 마침

    ```
    ~$ nmcli device status

    ~$ nmcli connection modify "name of ethernet" ipv4.addresses ip/subnetmask ipv4.gateway gateway ip

    ~$ nmcli connection modify "name of ethernet" ipv4.dns "dns1 dns2"

    ~$ nmcli connection modify "name of ethernet" ipv4.method manual

    ~$ nmcli connection up "name of ethernet"
    ```

    이후 원활한 외부 접속을 위해 tailscale 설정

    ```
    ~$ curl -fsSL https://tailscale.com/install.sh | sh
    
    ~$ sudo tailscale up
    ```

    설치 과정에서 시간대가 맞지 않는 상황 발생 이를 해결 이후 RTC가 없고 NTP 포트가 막혀있기에 htpdate 설치해 신간 최신화 적용

    ```
    ~$ sudo date -s "2026-08-24 10:43:00"

    ~$ sudo apt install htpdate
    ```
