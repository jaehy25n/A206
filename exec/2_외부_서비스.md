# 2. 외부 서비스

프로젝트가 가입하거나 내려받아 쓰는 외부 서비스 목록이다. 소셜 로그인, 결제, 포톤 클라우드 같은 서비스는 **쓰지 않는다**. 앱에 로그인이 없고 서버 API에도 인증이 없다.

| 서비스 | 쓰는 곳 | 용도 | 가입·설정 |
|---|---|---|---|
| **AWS EC2** | `cpu_server/` | 업로드 수신·전처리 서버 호스팅 (Ubuntu) | AWS 계정 → EC2 인스턴스 생성 → 키 페어(`.pem`) 발급. 보안그룹 인바운드: 22(SSH, GPU 서버와 관리자 IP), 80(HTTP, 수집 기기 IP) |
| **Google Play Services for AR (ARCore)** | `Tiger/` | 카메라 pose 추적 (ARCore SDK 1.56.0) | 가입 불필요. 기기에 Play 스토어의 "Google Play Services for AR" 설치. 앱이 없으면 첫 세션 시작 때 설치 화면을 띄운다. 지원 기기 목록: https://developers.google.com/ar/devices |
| **Weights & Biases** | `gpu_server/` | 학습 로그 (project `omx-umi`, `accelerate` tracker) | https://wandb.ai 가입 → API 키 발급 → GPU 서버에서 `wandb login` (키는 `~/.netrc`, mode 600). wandb **0.22.3 이상** 필요. 보고된 실행은 모두 `WANDB_MODE=offline` 이라 키 없이도 학습은 돈다 |
| **Hugging Face Hub** | `gpu_server/` | CLIP ViT-B/16 사전학습 가중치 내려받기 (timm `vit_base_patch16_clip_224`) | 가입 불필요 (공개 가중치). 첫 학습 때 `~/.cache/huggingface` 에 캐시된다. `huggingface_hub==0.25.2` 고정 |
| **PyTorch 패키지 인덱스** | `gpu_server/` | `torch==2.1.0+cu121` 휠 | 가입 불필요. `--extra-index-url https://download.pytorch.org/whl/cu121` |
| **conda-forge / RoboStack** | `gpu_server/` | Python 3.9 env의 `av`·`gym`, ROS 2 Jazzy·MoveIt·ros2_control | 가입 불필요. micromamba/mamba로 설치 (`env/*.yml`) |
| **GitHub (upstream 소스)** | `gpu_server/` | UMI `real-stanford/universal_manipulation_interface` @ `d095ba9`, `ros-controls/mujoco_ros2_control` @ `58f465b` | 가입 불필요. 공개 저장소 클론 |
| **Google Colab** (선택) | `gpu_server/colab/` | 학습 재현용 대안 환경 | Google 계정. `colab/omx_umi_colab.ipynb` 사용. 데이터셋과 체크포인트는 Google Drive에 올려 복사 |
| **Pretendard 글꼴** | `Tiger/` | 앱 글꼴 (앱에 번들) | 가입 불필요. SIL OFL 라이선스, `Tiger/app/licenses/Pretendard-OFL.txt` |

## 서비스 간 연결

```text
Tiger 앱 ──HTTP 80──▶ EC2 nginx ──▶ uvicorn :8000        (인증 없음, 보안그룹으로 제한)
GPU 서버 ──SSH 22 (ed25519 키)──▶ EC2 /srv/processed/v1  (rsync, 읽기 전용 pull)
GPU 서버 ──HTTPS──▶ wandb.ai                              (선택, offline이면 없음)
```

## 비밀값 보관 위치

| 비밀값 | 위치 | 저장소 포함 |
|---|---|---|
| EC2 키 페어 | 관리자 PC의 `*.pem` | ✕ |
| GPU→EC2 SSH 키 | GPU 서버 `~/.ssh/tiger_cpu_sync` (공개키는 EC2 `authorized_keys`) | ✕ |
| EC2 호스트 주소 | `Tiger/local.properties` (`tigerUploadBaseUrl`), GPU 서버 `config/cpu_sync.env` (`CPU_HOST`) | ✕ |
| W&B API 키 | GPU 서버 `~/.netrc` | ✕ |

실제 값은 팀 내부로만 전달한다. 이 문서와 저장소에는 적지 않는다.
